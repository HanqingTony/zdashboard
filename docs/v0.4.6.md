# v0.4.6 — 端口映射注册表改为对齐表格

发布日期：2026-10-27

右栏「端口映射注册表」从卡片行改成表格，端口更直观：

```
项目        上游端口          对外端口   监听      nginx
ComfyUI     127.0.0.1:8188 →  18130     ●监听中   ●转发中
dsh web     127.0.0.1:28110 → 18110     ●监听中   ●手工转发
```

- **端口字体 13.5px 等宽加粗**（原来 9.5px）
- **上游端口 / 对外端口固定列宽、各自右对齐**，跨行整齐
- 中间独立箭头列 `→`
- 监听状态单独一列：绿/灰灯 + 监听中/未监听
- nginx 状态单独一列：绿/黄/红/灰灯 + 转发中/手工转发/待应用/冲突/未转发
- 监听中的行有绿色顶部/底部边线和左侧绿条
- 操作列：主页、置顶、打开、移除端口
- 窄屏表格可横向滚动，左右栏在 <900px 自动上下堆叠

## 测试

纯 UI/CSS 调整，测试仍为 **30** 个用例。
