# v0.7.1 — 路线图节点快速录入

## 问题

v0.7.0 新建节点会打开一个完整表单：标题、类型、状态、日期、分类、描述、上级多选。填表感太重，和“在画布上长出一根分支”的初衷相反。

## 现在的创建方式

创建时只问标题，其他字段全部使用默认值：

- 顶部「＋ 愿景 / ＋ 项目」：在画布上弹出一个标题输入框
- 节点右上角 `＋`：直接在该节点下加子节点
- 选中节点后按 `Tab`：加子节点
- 选中节点后按 `Enter`：加同级
- 输入标题后：
  - `Enter` 保存并继续输入下一个同级
  - `Tab` 保存并在新节点下继续输入子级
  - `Esc` 或「完成」结束
  - 点击输入框外部也会保存并结束
- 类型按上下文推断：愿景下默认项目，项目/里程碑下默认里程碑；顶部按钮可显式建愿景/根项目
- 日期、分类、描述、状态、多上级仍然可以在右侧详情 → 编辑里补，不再出现在创建流程里

## 实现

- `public/roadmap.js` 新增 `rmQuick` 状态和 `rmQuickAdd / rmQuickOpen / rmQuickSave / rmQuickPosition / rmRevealNode`
- 快速创建成功后保留当前缩放/平移，只把新节点滚进可视区，不重新 fit
- `document` 级键盘：选中节点后 `Tab` 子节点、`Enter` 同级；输入框/弹窗内不拦截
- 手机端没有 hover，隐藏节点上的 `＋`，从底部详情点「＋ 子节点」；输入框位置按 viewport 夹紧，避免跑到屏幕外
- 后端 API 与 schema 不变，仍是 v8 DAG
