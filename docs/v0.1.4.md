# v0.1.4 更新记录

发布日期：2026-10-15 · 新增「热榜 / 趋势」板块

## 一、结论：哪些平台可行（全部**实测**过，不是查文档猜的）

| 平台 | 接口 | 性质 | 实测 | 结论 |
|---|---|---|---|---|
| **bilibili 热门** | `api.bilibili.com/x/web-interface/popular` | **官方公开**接口 | 200，20 条含播放量 | ✅ **已接** |
| bilibili 排行榜 | `…/ranking/v2` | 官方 | `code=-352`（风控，需 wbi 签名/cookie） | ❌ 未接（改用 popular） |
| **微博热搜** | `weibo.com/ajax/side/hotSearch` | 官方站点接口（免登录，未公开文档） | 200，51 条含热度 | ✅ **已接** |
| **知乎热榜** | `api.zhihu.com/topstory/hot-list` | 官方**移动端**接口（免鉴权） | 200，含热度 | ✅ **已接** |
| 知乎 web 端 | `www.zhihu.com/api/v3/feed/topstory/hot-lists/total` | 官方 | 401「身份未经过验证」 | ❌ 不可用（要登录态） |
| **抖音热榜** | `aweme.snssdk.com/aweme/v1/hot/search/list/` | 官方**旧版**接口（免签名） | 200，word_list 49 条含热值 | ✅ **已接** |
| 抖音 web 端 | `www.douyin.com/aweme/v1/web/hot/search/list/` | 官方新版 | 200 但**空 body**（需 `a_bogus` 签名） | ❌ 未接 |
| 小红书 | — | **无公开接口**；web 端要 `x-s`/`x-t` 签名（算法逆向，违反 ToS 且随时失效） | 404 / 需签名 | ❌ **不可行** |
| **Reddit** | `oauth.reddit.com/r/popular/hot`（OAuth client_credentials） | **官方 API**，免费注册 app（100 QPM） | 需 app 凭据；免认证 `.json` 走代理返回 **403**（IP 被挡） | ⚠️ **可接但需凭据** |
| **YouTube 趋势** | `googleapis.com/youtube/v3/videos?chart=mostPopular` | **官方 Data API v3**，免费 10k 单位/日 | 403「unregistered callers」→ 只缺 API key | ⚠️ **可接但需 API key** |
| X / Twitter 趋势 | `api.twitter.com/2/trends/by/woeid/:id` | **官方 API v2** | 401；且免费档**不含** trends（需付费 Basic 起） | ❌ **不可行**（不付费） |

**一句话**：国内四家（bilibili/微博/知乎/抖音）能用**官方接口**免凭据跑通；小红书没有任何公开接口（只有签名逆向，不做）；
外网三家都"官方可行但都有门槛"——YouTube 只差一个免费 API key、Reddit 要免费注册一个 app，X 必须付费，所以先做成**待配置**状态。

## 二、新增板块

- 分组 **中文热榜**：`hot-bilibili` / `hot-weibo` / `hot-zhihu` / `hot-douyin`
- 分组 **外网趋势**：`tr-youtube` / `tr-reddit`（**待配置**，卡片上直接给出申请指引）
- 热榜类**按榜单排名显示**（新增 `agg_item.ord` 列，排序 `(ord IS NULL), ord ASC, created_at DESC`），显示前 10 条；
  「新」语义不变：**榜单里第一次见到的词/话题**会打「新」标——等于"这次又冒出来什么"。

## 三、凭据与代理

- 凭据走 **环境变量文件** `/home/tony/zdata/zdashboard/agg.env`（权限 600，**不进仓库**），
  单元里加了 `EnvironmentFile=-/home/tony/zdata/zdashboard/agg.env`（可选，不存在也不报错）。填好后 `sudo systemctl restart zdashboard` 生效：
  ```
  YOUTUBE_API_KEY=…      # Google Cloud → 启用 YouTube Data API v3 → API 密钥
  REDDIT_CLIENT_ID=…     # reddit.com/prefs/apps → create app (script)
  REDDIT_CLIENT_SECRET=…
  ```
- **出境站点（YouTube/Reddit）显式走本机代理**：源上声明 `proxy: true`，实现用 `undici` 的 `ProxyAgent`
  （地址 `AGG_PROXY`，默认 `http://127.0.0.1:12809`）；**不走系统代理环境变量**，也不影响国内平台的直连。
- 源声明 `requires.env` 后，缺变量时状态是 **`unconfigured`（待配置）**：不探测、不报错、不标过期，卡片上显示缺哪个变量 + 怎么申请。

## 四. 怎么加源

`src/agg/sources.js` 里加一条即可（前端自动多一张卡）：

```js
{ id: 'hot-x', group: '中文热榜', label: '…', note: '…', homepage: 'https://…',
  display: 10, ranked: true,                       // 热榜：显示前 10、按排名
  requires: { env: ['SOME_KEY'], hint: '…' },      // 可选：需要凭据时
  proxy: true,                                     // 可选：需出境代理
  probe: async () => ({ items: [{ id, title, url, ord, createdAt, meta: [] }] }) }
```

## 五、同日 UI 调整（板块与上色）

- **两个板块**：上层 = **探针**（HuggingFace · civarchive —— 有没有新模型 / 新 LoRA）；
  下层 = **热门话题**（中文热榜 · 外网趋势 —— 头条热帖与最热趋势）。板块内保留分组小标题。
- **探针卡片按「最新条目日期」上色**（只看探针板块；热门话题无日期概念，不上色）：
  - 最新条目是**今天** → 绿色边框（`.agg-src.fresh`，带一点辉光）
  - 最新条目在**一周内** → 黄色边框（`.agg-src.recent`）
  - 更早 → 默认边框
  
  判定口径：`createdAt` 取该源展示条目里最新的一条，按**本地时区**的日期与今天比较
  （`diff<=0` 绿、`diff<7` 黄）；条目日期也一并改为本地时区显示，两者口径一致。
