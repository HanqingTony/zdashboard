# v0.10.0 — 服务导航运行指示灯

## 改动

服务导航的每个条目增加一个运行指示灯：

- **绿色发光**：探测端口正在监听
- **暗红**：端口未监听
- **无灯**：静态 `nav.json` 回退或条目没有端口信息

指示灯同时出现在主页服务卡片和左上角服务导航侧栏；鼠标悬停显示实际探测端口。

## 探测规则

`GET /api/nav` 统一补充：

```json
{
  "probePort": 28100,
  "running": true
}
```

- 有纯数字 `upstream` 时优先探测回环上游端口，例如 `18100 ↔ 28100` 探 `28100`
- `upstream` 是远程形式（如 `101:18200`）时探测 `port`，避免误判本机端口
- 没有 `upstream` 时探测 `port`
- 端口集合来自 `ss -ltnH`，缓存 5 秒；不会每次刷新都执行系统命令
- 只代表“端口在监听”，不是 HTTP 健康检查；进程假死但端口仍监听时仍显示绿灯

## 验证

- `/api/nav` 对静态服务和 PM 托管项目都返回 `running` / `probePort`
- 演示结果：`zDashboard 28100` 绿灯，`alooplayer 18190` 红灯，`avocal 12703` 正常探测本机入口而不是远程 `101:18200`
- `npm test`：47/47
