# v0.8.0 — 网页词析扩展与通用词库 API

## 新增

- **浏览器扩展** `extension/`：Chromium Manifest V3，可在 Chrome / Edge 单独加载使用
- **通用词库 API**：`zWordOccurrence` 表 + 批量状态/出处接口，JSON 请求，不绑定 SQLite 方言
- **两种存储模式**
  - 本地：扩展 IndexedDB 工作库，导入/导出 JSON、CSV
  - API：直接调用 zdashboard，写入**同一个 SQLite**，没有同步和第二份数据

## 状态语义

扩展里的「初始未标记」不是数据库里的 `unknown`（红），而是**无记录**：

| 页面 | 数据库 |
|---|---|
| 初始未标记、无色 | 没有记录 |
| 黄 · 不熟 | `familiar` |
| 红 · 不认识 | `unknown` |
| 无色 · 已掌握 | `mastered` |

点击循环：

```text
无记录 → familiar（黄）→ unknown（红）→ mastered（无色）→ familiar（黄）→ ...
```

段落右键「本段分析完成」：只把该段**没有记录**的词批量写为 `mastered`；已有黄/红状态的词保持不变，`clicked:false` 不增加点击次数。

## 数据表

迁移 **v9 `word-occurrences`**：

```sql
zWordOccurrence(
  id, word, status, source_url, source_title, context, context_hash,
  first_seen, last_seen, click_count
)
UNIQUE(word, source_url, context_hash)
```

`zVocab` 仍是当前状态主表。`zWordOccurrence` 记录一次词 + 页面 + 原句的出处，重复点击同一出处只更新时间、状态和点击次数。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/vocab/words?words=a,b` | 批量状态；无记录不返回（初始无标记） |
| POST | `/api/vocab/occurrences` | 批量 upsert；`clicked:false` 用于段落完成 |
| GET | `/api/vocab/occurrences?word=&limit=` | 导出/排查出处 |
| GET | `/api/vocab/stats` | 词条数/状态分布/出处数 |

`POST /api/vocab/occurrences` 是通用 JSON 接口，任何客户端都可以调用；扩展 API 模式只依赖这组接口。

## 扩展实现

- `manifest.json`：MV3，`activeTab` / `scripting` / `storage` / `contextMenus`
- `background.js`：本地 IndexedDB、API 转发、右键菜单、徽标、导入导出
- `content.js`：保守文本块识别、单词命中、CSS Custom Highlight、点击循环、段落完成
- `content.css`：只给 Text 片段做高亮，不给图标/按钮/视频盖透明层
- `options.html/css/js`：模式、API 地址/token、目录、JSON/CSV 导入导出

### 保守处理范围

只处理确定是正文的块：`p / li / blockquote / dd / dt / td / th / figcaption`，并跳过：

- `nav / header / footer / aside` 与应用 chrome
- `button / input / textarea / select / option`
- `code / pre / kbd / samp`
- `svg / canvas / video / audio / iframe`
- `contenteditable`
- 少于 40 字符或少于 6 个词的短块

因此滚动、视频、图片、图标和按钮交互不受影响；点击单词只在文字命中时拦截。首版不处理 iframe、Shadow DOM、PDF 和 canvas 文本。

## 使用

```text
Chrome / Edge → 扩展管理 → 开发者模式 → 加载已解压 → 选择 extension/
```

点击工具栏 Z 图标开启/关闭当前页词析。API 模式需要 zdashboard v0.8.0+ 和 `http://127.0.0.1:28100`（或你的局域网地址）。`AUTH_TOKEN` 开启时填写 `X-ZToken`。
