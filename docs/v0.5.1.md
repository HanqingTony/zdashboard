# v0.5.1 — 左上角改为服务导航，支持收藏置顶

发布日期：2026-10-27

左上角原来显示项目管理器的前 5 个项目，现在改为**服务导航**：

- 每条 = 一个 `/api/nav` 条目（静态 `nav.json` + PM 托管项目）
- 点击条目直接打开服务 URL
- 每条右侧有 ★：收藏后自动进入顶部「★ 收藏」区
- 收藏 key 用服务 URL，存浏览器 `localStorage`（`zdbNavFavorites`）
- 竖屏/横屏两侧栏共用同一份数据，跨标签页通过 `storage` 事件同步
- PM 里原来的项目「置顶」保留，但只影响项目管理器内部排序，不再影响左上角

## 端口与测试

纯前端/UI 调整，无迁移。测试仍为 **30** 个用例。

同时修正 `test/pm.test.js` 对宿主 `12710` 是否空闲的依赖：自动上游端口只断言落在
`12710–12799`，避免本机有服务监听时测试误报。
