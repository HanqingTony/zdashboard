# v0.4.2 — 端口映射注册表：监听高亮 + nginx 转发绿灯

发布日期：2026-10-27

右栏从普通列表升级成「端口映射注册表」，把三个状态直接画出来：

| 状态 | 表现 |
|---|---|
| 上游在监听 | 整行**绿色边框高亮** |
| nginx 正在对外反向代理 | 行内**绿灯 + 「转发中」** |
| 已有手工 nginx 映射（不在 PM 生成文件） | 绿灯 + 「手工转发」（加一圈光环区分） |
| 已启用但还没应用 | 黄灯「待应用」 |
| 对外端口被别的 upstream 占用 | 红灯「冲突」 |
| 未启用 | 灰灯「未转发」 |

> “nginx 对外转发”技术叫**反向代理（reverse proxy）**；口语说转发没问题。

## 注册表

- 只要分配了 `upstream_port + external_port` 就出现在右栏，不管 nginx 开没开
- 注册表标题显示：`N 条 · M 监听 · K 转发`
- 后端 `/api/pm` 每条新增：
  - `upstreamListening`
  - `nginxState`：`forwarding | manual | pending | conflict | off`
  - `nginxMappedUpstream`
- `nginxState` 来自**实际读取活动 nginx conf**（`conf.d/*.conf` + `sites-enabled`）解析 `listen ↔ proxy_pass`，不是只看 DB 开关；因此手工映射的 dsh/comfy-web/MinIO/searxng/zres 也会亮绿灯

## 新建项目

顶部新增 **「+ 新建项目」**：默认同时建仓库 + 注册端口，创建后立即出现在右栏注册表；也可以取消其中一项。

左侧仍可单独「+ 仓库」，右侧仍可「+ 注册端口」；两边都保留独立入口。
