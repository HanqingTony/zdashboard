# v0.2.1 — 第二轮全面修复（正确性收尾 / 运维闭环 / 可访问性）

发布日期：2026-10-20

v0.2.0 清掉了大部分历史债；这一版修的是复查中发现的**残留缺陷**（其中两个是 v0.2.0 新加保留策略里的漏洞），并把备份、CI、systemd 权限这些运维闭环补上。

## 聚合

- **保留策略不再只靠「全部刷新」触发**：任何单源/全量刷新后最多每小时清理一次；否则自动刷新是逐源的，`agg_item` 实际会无界增长
- **热榜保留排序修正**：从 `first_seen DESC` 改为 `last_seen DESC, first_seen DESC`——长期在榜的条目不会因为首次见到时间老而被误删、再当「新」出现
- **版本探针的 `git describe` 异步化**：原来 `execFileSync` 最坏阻塞事件循环 10 秒
- **已读水位补齐**：`pagehide` / `visibilitychange(hidden)` 时用 `fetch(..., {keepalive:true})` 补 ack；关标签页/手机锁屏不再永远未读
- **长驻页面自动更新**：每 5 分钟拉一次未读数；在聚合页时顺便刷新过期源
- **时间语义**：API 分别返回 `lastOkAt` / `lastAttemptAt`，前端显示「上次成功 / 上次尝试」；去掉永远被覆盖的 `lastRefreshAt` 变量（保留字段兼容）
- **每日榜 ID 带日期**：Google Trends / Wikipedia / Mastodon / Bluesky / 微博 / 抖音按天去重，同一话题隔天再上榜会重新提醒（bilibili 用 bvid、知乎用 question id，本身唯一）

## Vocab

- **URL / 邮箱 / 行内代码 / 围栏代码块不入库**：仍原样显示，但不可点、不计数，避免污染词库
- **大文章分段渲染**：每段 12000 token，先显示第一段，其余点「继续显示剩余 N 词」；不再一次插入十万级 `<span>` 卡死浏览器
- **词状态白名单**：只接受 `mastered/familiar`，历史脏数据统一落到 `unknown`，杜绝 `class` 属性注入
- **非颜色区分**：familiar 加点状下划线、unknown 加波浪下划线（色盲可用）；恢复页面缩放（移除 `user-scalable=no`）
- 增加 `:focus-visible` 焦点样式

## 台账 / 前端

- 状态/层/判决/Kind 枚举集中到前后端共用的 **`public/projects-meta.js`**，不再四处复制字面量
- **侧栏项目列表接真实台账**（`/api/projects` 前 5 条，点击进入台账）；删除 Diary/Reminders 的假角标
- **顶栏接真实数据**：台账总数 / 聚合未读数 / 版本号；移除写死的 `MinIO 2.4G`、`HS 3`
- 项目状态圆点补齐「欠账（红）/归档（灰）」

## 安全 / 服务端

- 鉴权中间件提前到 `express.json` **之前**：未认证请求不再先解析 2MB body
- `/api` 固定窗口限流（180 次/分钟/IP，429 + `Retry-After`）
- 安全响应头：CSP（本站脚本/样式）、`X-Frame-Options: DENY`、`nosniff`、`no-referrer`
- 生产环境 500 不再回传内部错误文本（可能含 SQL 细节）
- 新增可选 `ALLOWED_HOSTS`（Host 白名单，防 DNS rebinding，默认关闭）
- `/api` 响应统一 `Cache-Control: no-store`

## 运维 / 工程化

- **备份闭环**：`scripts/backup.js`（`db.backup()` 在线备份 + 保留 N 份）+ `npm run backup` + `deploy/zdashboard-backup.service/.timer`（每天 04:00）
- **systemd 最小权限**：`deploy/zdashboard.service` 增加 `NoNewPrivileges` / `ProtectSystem=strict` / `ProtectHome=read-only` / `ReadWritePaths=/home/tony/zdata` 等；移除 `AUDIO_DIR`
- `git status` / `git describe` 统一 `GIT_OPTIONAL_LOCKS=0`，只读 home 下也能工作
- **CI**：`.github/workflows/test.yml`（npm ci + npm test，审计非阻塞）
- Dockerfile 复制 `scripts/`；测试增至 **24 个用例**（新增限流、保留排序、共享枚举等）
- README / AGENTS / 目录树同步

- **独立迁移框架**：目前只有 5 张表，幂等 DDL + `ensureColumn` 足够；引入版本化迁移会动生产库，收益不成比例
- **枚举存 code（active/ondemand）**：需要迁移现有生产数据，风险高于收益；先做共享常量消除重复
- **拆分 `public/app.js`**：纯结构重构，无功能收益，留到下次动前端时做
- **删除历史表 `zInfra`/`zObjects`**：包含用户数据，需你确认后手工清理
- **`.run`/Docker 构建验证**：本机拉取 node 镜像超时，未完成验证（需在有网环境跑一次 `bash deploy/build_run.sh`）
