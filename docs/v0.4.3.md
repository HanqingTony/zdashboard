# v0.4.3 — 新建仓库默认自动分配并注册端口

发布日期：2026-10-27

修复：左栏「+ 仓库」之前固定 `managePorts:false`，只建仓库，不注册端口；现在默认自动分配一组 `127xx ↳ 181xx` 并写入端口映射注册表。

## 变更

- 左栏「+ 仓库」表单新增：
  - ☑ 自动注册端口（127xx ↳ 181xx）—— 默认开
  - ☑ 启用 nginx —— 默认开
  - ☑ 挂到主页 —— 默认开
  - ☑ 配置双远端 —— 默认开
- 创建后：
  - 仓库出现在左栏
  - 自动分配的端口出现在右栏注册表
  - 若启用 nginx，root apply unit 会生成对外映射；上游未启动时显示「转发中」但行不绿框（绿框只表示上游在监听）
- 仍可取消「自动注册端口」只建仓库；也可以取消 nginx/主页只登记端口。
- 顶部「+ 新建项目」逻辑不变（默认建仓 + 端口）。

## 测试

新增「新建仓库默认自动分配端口」用例，共 **30** 个。
