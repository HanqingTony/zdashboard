## 二、实现要点

- **走 atom feed，不走 GitHub REST API**：实测共享代理出口 IP（104.168.175.88）的 API 限额（60/时，未认证）经常吃光；`*.atom` 走 web 域不限额、免 key。
- **网络**：`proxyMode: 'auto'`（先直连后代理，复用既有 fetchText）。实测本机 Node 直连 github.com 会在 ~10s 后失败（curl 直连却通，TLS 层差异），随后代理 ~1s 成功，单探针总耗时 ~12-14s；30 分钟 TTL + 全源并发刷新，不构成瓶颈。
- **本地版本**：`execFileSync('git', ['-C', dir, 'describe', ...])`（5s 超时），路径按 zscript 默认值 `~/zrepo/{llama.cpp,fastllm}`，不引入新环境变量。
- **版本号比较**：`b####`（构建号）与 `vX.Y.Z`（语义号）各自转数字数组比较，格式不一致时不比较、只展示。
- 前端零改动：通用渲染（组 = `版本更新`，探针板副标题已加「版本更新」字样）。
