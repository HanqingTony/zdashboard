# v0.4.1 — 项目管理器左右分栏：仓库 / 端口彻底解耦

发布日期：2026-10-27

v0.4.0 把台账删掉后，项目管理器仍是一张混合列表；这一版把「仓库管理」和「端口管理」拆成左右两栏，并让删除/扫描也分开。

## UI

```
┌─────────────────────────────┬─────────────────────────────┐
│ 📦 仓库管理  [扫描仓库][+仓库] │ 🔌 端口管理 [扫描服务][+端口] │
│  - 仓库路径 / 最近提交 / 脏   │  - 127xx ↳ 181xx / 上游状态  │
│  - 双远端 / 置顶 / 移出仓库   │  - nginx/主页/打开/移除端口  │
│  - 无端口时显示「+ 端口」      │  - 成品软件也可以只有端口     │
└─────────────────────────────┴─────────────────────────────┘
```

- 同一行两边都有时，会同时出现在左右栏（例如 ComfyUI）。
- 左栏删除仓库 → 端口保留；右栏移除端口 → 仓库保留；两边都没了才删除整条。
- 仓库行没有端口时提供「+ 端口」，可直接给该仓库补端口映射。
- 窄屏（<900px）自动上下堆叠。

## API

- `DELETE /api/pm/:id/repo`：解绑仓库（保留端口）
- `DELETE /api/pm/:id/ports`：移除端口（保留仓库）
- `POST /api/pm/scan?what=repos|ports|all`：分开扫描仓库 / 运行服务
- 新建：仓库用 `createRepo=true, managePorts=false`；端口用 `createRepo=false, managePorts=true`

## 实际效果

生产 19 条中：

- 左栏仓库 **17** 条（含 ComfyUI/dsh/comfy-web/zres 这些仓库+端口的条目）
- 右栏端口 **6** 条（ComfyUI / dsh / comfy-web / zres / MinIO / searxng）
- ComfyUI 仍在 `18130` 正常代理；现有手工映射的 5 个服务端口只登记，nginx 开关保持关闭
