# v0.4.0 — 取消项目台账，项目管理器接管全部项目管理

发布日期：2026-10-27

## 破坏性变更

- **删除「📋 项目台账」**：前端入口、`/api/projects`、`src/projects/`、`public/projects*.js`、`seed.json`、导入/评分/判决功能全部移除。
- **数据库迁移 v6 删除 `zproject` 表**；部署前用 `scripts/archive-legacy.js --drop` 把旧台账归档到 `BACKUP_DIR/legacy/`。
- 「主界面左上当前项目」改为读取项目管理器（`/api/pm` 前 5 条），不再是台账。

## 项目管理器成为唯一项目管理入口

一个条目现在可以独立拥有：

| 功能 | 字段 | 例子 |
|---|---|---|
| 仓库 | `repo_path` / `repo_created` / `dual_remote` | 普通自研项目、扫描到的 `/home/tony/zrepo/*` |
| 端口映射 | `upstream_port` / `external_port` / `nginx_enabled` | ComfyUI `8188 → 18130`、MinIO 只登记 `28101 → 18101` |
| 主页挂载 | `web_enabled` | 启用后 `/api/nav` 出现「我的项目」卡片 |

- **端口与仓库解耦**：可以只有仓库（无端口）、只有端口（成品软件）、或两者都有。
- 新建项目仍可一键建仓 + 双远端 + 端口 + nginx + 主页。
- **扫描本机**（`POST /api/pm/scan` / `npm run pm:scan`）：
  - 扫描 `PM_REPO_ROOT` 下所有含 `.git` 的目录
  - 扫描正在运行的已知服务：ComfyUI、dsh web、comfy-web、MinIO、searxng、zres
  - 已有手工 nginx 映射的服务以 `nginx_enabled=0` 登记，避免与 `zports-external.conf` 重复 listen
- **同步 git**（`POST /api/pm/sync`）：刷新 last commit / 脏文件 / 未推送 / 双远端。
- 左上「当前项目」、PM 列表、主页黄页三处都从 `managed_project` 读取。

## nginx 应用

- App 只写 `PM_STATE_DIR/pm-nginx.conf`；root 的 `zdashboard-nginx-apply.path/service` 校验后安装、`nginx -t`、reload，失败回滚。
- 端口校验放宽为：对外 `18100–18199`；上游 `1–65535`（ComfyUI 8188 可直接映射），但仍只允许 `http://127.0.0.1:<port>`。
- 已有手工映射的条目不能再启用 nginx（会检测其它 conf 的 `listen`），避免端口冲突。
