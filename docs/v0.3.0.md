# v0.3.0 — 项目管理器（建仓 / 端口 / nginx / 主页挂载）

发布日期：2026-10-27

新增 Tools → **🛠 项目管理器**：把「新建项目」从手工建仓、配远端、找端口、改 nginx、加黄页这一串操作收进一个页面。

## 新建项目

一次操作完成：

1. **分配端口**：默认上游 `12710–12799`，对外 `18130–18189`；自动扫描 `ss` 监听、活动 nginx conf、`nav.json`、`managed_project` 表，跳过已占用；也可手填。
2. **建本地仓库**：`/home/tony/zrepo/<slug>`，`git init -b main` + 初始 `README.md` + 首次提交。
3. **配置双远端**：`origin` fetch 走 GitHub；pushurl 配 GitHub + Gitee（与 `zpa/setup-dual-remote.sh` 一致），`git push origin main` 即双推。**远端仓库本身需先在 GitHub/Gitee 创建**，管理器只配置 URL。
4. **生成初始说明**：README 写入上游/对外端口与启动方式。
5. **写 nginx 期望状态**：启用时立刻生成对外映射。

## 管理

- 每个项目独立开关：**nginx 映射** / **挂到主页**。
- **主页挂载**：`GET /api/nav` 把静态 `public/nav.json` 与托管项目合并，在黄页顶部生成「我的项目」分组；关掉「主页」即消失。
- 删除只删管理记录（并移除 nginx 映射），**仓库目录保留**。
- 上游是否监听实时显示；未启动时映射仍在，访问会 502。
- 新建/切换后页面自动轮询 nginx 应用状态。

## nginx 应用（root 边界）

App 不直接写 `/etc/nginx`，也不调用 sudo：

```
app → /home/tony/zdata/zdashboard/pm-nginx.conf（期望状态）
      ↓ systemd path unit（root）
zdashboard-nginx-apply：
  1. 校验首行标记 + 对外 18130-18189 / 上游 12710-12799
  2. install 到 /etc/nginx/conf.d/zdashboard-projects.conf
  3. nginx -t 失败 → 自动回滚 + 写错误状态
  4. 成功 → systemctl reload nginx + 写 pm-nginx-status.json
```

- 单元：`deploy/zdashboard-nginx-apply.service` / `.path`
- 脚本：`deploy/zdashboard-nginx-apply.sh` → `/usr/local/sbin/`
- 状态：`pm-nginx-status.json`（app 读取，前端显示「已应用 / 失败」）
- 主服务 unit 增加 `ReadWritePaths=/home/tony/zrepo`（建仓需要），其余仍是 `ProtectHome=read-only`

## 安全

- 写操作需要 `PM_TOKEN`（请求头 `X-PM-Token`）或全局 `AUTH_TOKEN`；未配置时写接口返回 403，GET/主页仍只读可用。
- 前端首次写操作会提示输入口令，存 localStorage。
- 所有路径/端口/slug 服务端校验；仓库路径强制在 `PM_REPO_ROOT` 下；nginx 端口段由 root 脚本二次校验。
- 不自动 push、不自动创建远端仓库、不启动项目进程。

## 数据 / 配置

- 表 `managed_project`（schema v5）：slug、name、repo_path、upstream_port、external_port、nginx_enabled、web_enabled、repo_created、dual_remote。
- 端口段、公开主机、仓库根、远端模板可用环境变量覆盖（见 README/AGENTS）。
- 新增测试：端口分配、建仓双远端、nginx 期望状态（共 **31** 个用例）。

## 部署清单

1. 主服务 unit 更新（`ReadWritePaths` 加 `/home/tony/zrepo`）并重启。
2. 安装 root helper + path/service unit，`enable --now zdashboard-nginx-apply.path`。
3. `agg.env` 增加 `PM_TOKEN=<随机串>`，重启 zdashboard。
4. 首次打开项目管理器，点「新建项目」时输入 PM_TOKEN。

## 已知边界

- 远端仓库创建仍是手工（GitHub/Gitee 平台操作）；管理器只配置双推 URL。
- 项目进程（如何监听 127xx）不由管理器启动；可在项目 README 里写启动命令，后续可加 systemd user unit。
- 端口段固定为 127xx/181xx；如需 28xxx 规范需另加映射规则。
