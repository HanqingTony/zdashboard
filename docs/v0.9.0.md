# v0.9.0 — Ask 咨询入口

## 页面

`Tools → 💬 Ask`：一个输入框为核心，同一条问题可以发往不同引擎，发送时自动留档。

- 引擎：DeepSeek / 知乎 / Grok / Claude / 本地 Pi session / 本地 SearXNG
- 当前引擎高亮；切换后保留草稿
- `⌘ / Ctrl + Enter` 发送
- 最近 30 条问题自动记录；点击历史可复用问题和引擎
- 外部引擎打开新标签，同时把问题复制到剪贴板
- 本地 Pi 的回答直接显示在页面内，不打开新标签

## 引擎行为

| 引擎 | 行为 |
|---|---|
| DeepSeek | `https://chat.deepseek.com/?q=` 尝试预填；同时复制问题 |
| 知乎 | `https://www.zhihu.com/search?type=content&q=` |
| Grok | `https://grok.com/?q=` 尝试预填；同时复制问题 |
| Claude | `https://claude.ai/new?q=` 尝试预填；同时复制问题 |
| 本地 Pi | 选择本机 session，POST `/api/ask/pi`，读取该 session 上下文回答 |
| SearXNG | `https://192.168.0.102:18102/search?q=` |

**预填限制**：普通网页无法跨域操作已打开的官网 tab。DeepSeek/Grok 是否接受 `?q=` 取决于官网；不接受时会退化为“已复制，手动粘贴”。要做到官网输入框 100% 自动填入，需要在浏览器扩展里针对站点注入 content script（本版未做）。

## 本地 Pi session

- `GET /api/ask/pi/sessions` 扫描 `~/.pi/agent/sessions`，返回 id / cwd / 修改时间 / 大小
- `POST /api/ask/pi` 只接受已存在 session id；把 session JSONL 复制到临时目录后运行：

```text
pi --session <临时副本> --no-tools --no-mcp --no-extensions --no-context-files --print -- <question>
```

- 不写回原 session，不执行工具，不改仓库
- 超时 120 秒；输出上限 8MB；临时目录在 finally 清理
- 生产 systemd 的 `ProtectHome=read-only`：auth/models/settings 复制到临时 agent 目录，通过 `PI_CODING_AGENT_DIR` 指向临时目录，避免 Pi 写 `~/.pi` 失败
- `PI_BIN` 可覆盖 pi 路径；`PI_AGENT_DIR` / `PI_SESSION_DIR` 可覆盖配置目录与 session 根目录
