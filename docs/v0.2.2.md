  1. `vocab-tables`（zVocab / zArticles / zWordArticles）

  3. `project-table`（zproject / 索引）
  4. `project-enums-to-codes`（旧 emoji/中文 status/layer → code）
- 老库（user_version=0）直接顺序跑完；新库同一套路径；`ensureColumn` 保证重复部署幂等。
- 已验证生产库副本：126 条台账全部映射成功（active/idea/...、l0..l4），agg 数据原样保留。

## 台账枚举改为稳定 code

- 存储：`status = active | on_demand | maintenance | paused | debt | upstream | archived | idea`
- 存储：`layer = l0 | l1 | l2 | l3 | l4`
- 展示仍在 `public/projects-meta.js` 统一映射（`🟢活跃`、`L0 在做`…），前后端共用。
- 后端 `create/update/upsert` 接受 code 或旧 emoji/中文值（自动归一化），旧调用不会坏。
- 筛选、编辑下拉、统计"在办"计数、侧栏状态点全部改用 code，不再依赖中文字符串。

## 前端拆分

`public/app.js` 从 ~1050 行拆成：

```
public/
├── app.js        # 启动入口（注册应用 + 初始化角标）
├── core.js       # 工具函数 / 侧栏 / 应用注册表 / 布局 / 状态栏
├── vocab.js      # 英语学习
├── nav.js        # 服务导航
├── agg.js        # 信息聚合
├── projects.js   # 项目台账
├── tokenize.js   # 前后端共用分词
└── projects-meta.js
```

- `core.js` 维护应用注册表（`registerApp`）与 `switchApp`；模块只负责自己的渲染与事件。
- 离开聚合页的已读水位通过注册表的 `onLeave` 钩子触发，不再在 core 里硬编码 `agg`。
- 所有 inline `onclick` 需要的函数仍由各模块挂到 `window`（无构建步骤不变）。
- jsdom 无头冒烟覆盖：启动、四应用切换、旋转、编辑下拉、分段渲染、URL 跳过、状态清洗、全局 handler —— 0 错误。
- 拆模块后 JS/CSS 改为 `Cache-Control: no-cache`（模块 `import './core.js'` 不带版本号，不能沿用 1h 强缓存）。
