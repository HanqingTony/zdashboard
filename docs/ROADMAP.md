## v0.5.0（计划中）

> 以下为原 v0.2.0 的功能计划，因 v0.2.0 用于清欠而顺延。

### 词汇量精准度量
- **核心思路**：不依赖选择题测验，而是建立足够大且精准的系统词库；词库覆盖率足够时，用户已掌握词的数量天然等于词汇量估值
- **数据结构升级**：重构 `zVocab`，需支持更细粒度的词维度：
  - 系统词库（zWordBank）：预置大规模英文词表，每个词携带词频分级、音标、释义、例句等元数据
  - 用户词状态：不止三态（unknown/familiar/mastered），需记录邂逅次数（exposure_count）、主动标白次数（mark_mastered_count）、最近复习时间等
  - 词汇量 = mastered 词数 / 系统词库覆盖率，无需单独测试模块
- **数据来源**：通过用户持续提交文章自然积累，辅以预置词库作为基准

### 文章搜寻/生成模块
- **目的**：为系统词库扩张和词汇量度量提供语料来源
- 根据指定主题/关键词，自动搜寻或生成英文文章
- 对接外部 API（新闻 API、Wikipedia 等）获取真实语料
- 或接入 LLM 按指定难度级别、目标词汇生成文章
- 文章自动入库并分词，与 Vocab 系统打通
- 基于用户已掌握的词汇推荐合适难度文章（i+1 输入假说）

### 资源管理模块
- 接入 MinIO，在线管理文件（浏览、上传、下载、删除）
- 文件元信息组织数据库：标签、分类、描述、关联关系
- 替代目前通过文件路径硬编码的音频播放方式

### 英语学习模块增强
- 单独的单词本页面：按状态筛选、搜索、批量操作
- 单词本独立于文章，可手动添加/删除单词

### 文章分析模块
- 一键全部标白按钮：将当前文章所有单词标记为 mastered

### 备份模块
- 一键备份：导出 zdb.db + 音频文件 + MinIO 数据
- 备份监控：显示最近备份时间、备份大小、自动提醒

### LLM 语音模块改进
- 将 TTS 模型编译为 WASM，直接在前端运行
- 去除对 ComfyUI 后端的依赖，实现离线语音合成

### 项目管理页面
- 监视仓库/分支/提交编号
- 展示各项目部署状态和版本信息
