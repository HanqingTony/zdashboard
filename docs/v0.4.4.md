# v0.4.4 — 仓库行显示端口号 + 监听绿灯

发布日期：2026-10-27

左栏「仓库管理」里，凡是已经分配端口的仓库行：

- 直接显示端口对：`127.0.0.1:8188 ↳ 18130`
- 上游正在监听 → **绿灯 + 「监听中」**（同时整行绿色边框）
- 未监听 → 灰灯 + 「未监听」

没有端口的纯仓库行保持原样，不显示灯和端口。

注意两个绿灯语义：

- **左栏绿灯** = 上游服务在监听（端口有人在用）
- **右栏注册表绿灯** = nginx 正在对外反向代理（配置存在，即使上游挂了也会亮）

两端都有的条目（如 ComfyUI）会同时出现在左右栏，分别显示各自状态。
