# v0.4.5 — 取消项目管理器口令（PM_TOKEN）

发布日期：2026-10-27

按使用者要求，项目管理器不再使用独立的 PM 管理口令：

- 删除 `PM_TOKEN` 配置、`X-PM-Token` 请求头、前端口令弹窗与 localStorage
- `/api/pm` 的新建/开关/扫描/同步/删除接口不再要求口令
- 仍保留可选的全局 `AUTH_TOKEN`：如果启用，它依旧保护所有 `/api/*`
- 生产 `agg.env` 中的 `PM_TOKEN` 已移除

> 安全说明：当前 `AUTH_TOKEN` 未启用，因此局域网内能打开面板的设备都可以创建仓库、改 nginx 映射。只在可信内网使用；若要收紧，设置全局 `AUTH_TOKEN` 即可（PM 会一并受保护）。

## 测试

`test/pm-api` 改为无口令写入，共 **30** 个用例。
