# v0.6.0 — 个人路线图

发布日期：2026-10-30

## 新增

Tools 新增 **◇ 路线图** 页面：

- 个人目标：标题、分类、状态（进行中 / 暂停 / 完成）、目标日期、描述
- 树形里程碑：无限层级子项，状态 `todo / doing / done / blocked`
- 纵向树视图：缩进 + 连接线、父节点完成比、分支折叠、实时汇总进度
- 目标与里程碑增删改；里程碑可换上级，服务端拒绝移动到自身或子节点下
- 删除目标级联删除里程碑，删除里程碑级联删除子项
- 左侧目标列表、顶部总目标数 / 完成里程碑 / 总完成度
- 桌面与移动端自适应；弹窗居中

## 数据与接口

- 迁移 v7 新增：
  - `roadmap_goal`
  - `roadmap_node`（`parent_id` 自引用，`ON DELETE CASCADE`）
- 新路由 `src/routes/roadmap.js`：
  - `GET /api/roadmap`
  - `POST|PATCH|DELETE /api/roadmap/goals[/:id]`
  - `POST|PATCH|DELETE /api/roadmap/nodes[/:id]`
- 进度不落库，由前端按树计算；总完成度按全部里程碑完成数计算
- 写操作结束调用 `checkpoint()`；时间统一 `nowIso()`

## 前端

- 新模块 `public/roadmap.js`，通过 `registerApp('roadmap', ...)` 注册
- 样式位于 `public/style.css` 的 `.rm-*` 段
- 树形连接线随缩进断点同步调整（桌面 / 900px / 560px）
- 折叠状态只保存在当前页面内存，刷新后恢复全展开
- 增加 `public/favicon.svg`，消除浏览器 `/favicon.ico` 404
